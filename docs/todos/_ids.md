# Todo ID Registry

Every iterative todo carries a 3–5 uppercase-letter ID prefixing its folder and anchoring
cross-references (`{ID}-{NNN}` plan form). IDs are unique across active and completed todos
and are never reused. Legacy flat-file todos use an older H/M/L/C + number series; those IDs
stay reserved for their files but new todos use this registry.
