# Neatoo 0.24.0

**Release Date:** 2026-03-23
**Type:** Feature
**Breaking Changes:** No

---

## Summary

Source generator now respects `private set` on partial properties. Properties declared with `private set` generate read-only interfaces, use `SetPrivateValue()` in the setter body, and have `IsReadOnly = true` at runtime. `IValidateProperty` gains `SetPrivateValue` as a public interface method.

---

## What's New

### Private Setter Support in Source Generator

The source generator respects setter accessibility on partial properties:

- `public partial decimal Total { get; private set; }` generates a `private set` accessor calling `SetPrivateValue(value)`, and emits `get;` only on the interface
- `protected set` and `internal set` preserve their accessor keyword but use the standard `.Value = value` path
- LazyLoad properties with `private set` use `LoadValue(value)` (LazyLoad already bypasses IsReadOnly)

This enables computed/derived properties that are writable from within the entity (via `AddAction` rules) but read-only to external consumers. MudNeatoo components automatically bind `ReadOnly="true"` for private-set properties through the existing `IsReadOnly` mechanism.

### IValidateProperty.SetPrivateValue

`SetPrivateValue(object? newValue, bool quietly = false)` is now part of the `IValidateProperty` public interface. The method already existed on `ValidateProperty<T>` as `public virtual` -- promoting it to the interface formalizes existing behavior and enables generated code to call it through the typed backing field without casting to concrete types.

---

## Migration

No migration required. Existing code is unaffected. To use private setters, declare properties with `private set`:

```csharp
public partial decimal ComputedTotal { get; private set; }
```
