# Neatoo 0.35.0

**Release date:** 2026-09-29
**Breaking changes:** No

## Summary

Custom `EntityProperty<T>` subclasses now survive the JSON round trip to a client. An application can
supply its own property type through `IPropertyFactory<T>` (for example one exposing a plausible range
read from an attribute, beside `IsValid` / `IsBusy` / `IsReadOnly`) and have it arrive on the client
with its modification state and attribute-derived metadata intact.

## What's new

### Fixed: an `EntityProperty<T>` subclass lost `IsSelfModified` on deserialization

The converter chose the entity-property constructor only when the property type's generic definition
was exactly `EntityProperty<>`. Any subclass failed that test and was built through the
`ValidateProperty` constructor branch, dropping `IsSelfModified`. For a subclass without a
four-argument constructor, deserialization threw instead. The check is now
`typeof(IEntityProperty).IsAssignableFrom(propertyType)`, so every entity property type takes the
entity branch.

Before this release, no `EntityProperty<T>` subclass round-tripped correctly.

### `EntityProperty<T>.ApplyPropertyInfo` is `virtual`

`EntityPropertyManager.OnDeserialized` calls `ApplyPropertyInfo(IPropertyInfo)` on each property to
restore metadata that is not serialized, such as `DisplayName`. It is now `public virtual`, so a
subclass can override it to restore its own attribute-derived state the same way, with nothing extra
on the wire. The `IEntityProperty` interface member is unchanged.

### Documented: custom property types

- `IPropertyFactory<T>`'s doc comment is corrected. It said to register a custom implementation in DI,
  but `EntityBaseServices<T>` always constructs its own `EntityPropertyFactory<T>` and never resolves
  `IPropertyFactory<T>`. For an `EntityBase`, wrap the injected `IEntityBaseServices<T>` and replace
  `PropertyFactory`. (`ValidateBaseServices<T>` does resolve it from DI.)
- The neatoo skill's properties reference gains a **Custom Property Types** section with the
  serialization contract: an open generic with one type parameter, the five-argument
  `[JsonConstructor]` `(string name, T value, bool isSelfModified, bool isReadOnly, IRuleMessage[] serializedRuleMessages)`,
  an assembly registered with `AddNeatooServices`, and a linker root for that constructor on trimmed
  WASM clients.
- New design sample: `src/Design/Design.Domain/PropertySystem/CustomPropertyType.cs`.

## Migration

None required.
